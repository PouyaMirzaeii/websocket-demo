# ⚡ Real-Time WebSocket Demo

A clean, modern, and light-weight full-stack application demonstrating real-time bidirectional communication using **WebSockets** and **Node.js**.

## 🚀 Features
- 🟢 **Live Status Indicator** with real-time state detection.
- 💬 **Broadcast System** (Messages delivered instantly to all open clients).
- 🎨 **Modern Dark UI** built with plain CSS.
- 📦 **Zero heavy frameworks** — Vanilla JS & Express + `ws`.

## 🛠️ Quick Start

```bash
# 1. Clone repo
git clone [https://github.com/YOUR_USERNAME/websocket-demo.git](https://github.com/YOUR_USERNAME/websocket-demo.git)
cd websocket-demo

# 2. Install dependencies
npm install

# 3. Start server
node server.js
